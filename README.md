# Phone Catalog Project | [DEMO PAGE](https://nemh.github.io/Phone_Catalog/)
This project showcases a modern, fully-featured phone and gadget e-commerce catalog website designed to help users effortlessly browse, filter, and select high-quality smartphones, tablets, and accessories.

## ⚙️ Technologies Used
* **React** — Component-based UI architecture with hooks (`useEffect`, `useContext`).
* **TypeScript** — Strict typing for predictable development and reliable data structures.
* **React Router DOM** — Dynamic client-side routing for seamless page navigation.
* **SCSS Modules** — Modular, isolated styling with custom mixins and BEM-like structure.
* **React Context API** — Global state management for shopping cart and favorites.
* **LocalStorage API** — Persistent data synchronization to keep the cart and favorites saved across browser sessions.
* **CSS Animations & Keyframes** — Smooth transitions, staggered mobile menu delays, and micro-interactions.
* **[SwiperJS](https://swiperjs.com/)** — Modern, mobile-touch slider and carousel integration for fluid product showcases.

## ⭐ Features:
* **📱 Fully Responsive Design:** The layout adapts flawlessly to smartphones, tablets, and desktops using a flexible responsive grid system and media mixins.
* **🎨 Multi-Theme Support:** Features a seamless theme-switching system (supporting multiple theme layouts) accessible instantly via a single global toggle button.
* **💾 Persistent State:** All user selections for the Shopping Cart, Favorites and Theme are saved locally and synchronized automatically via LocalStorage.
* **🎬 Immersive UI/UX Animations:** Enhanced user experience featuring staggered navigation loading (`:nth-child` animation delays) and smooth cubic-bezier hover zoom effects on product category cards.
* **🔒 Smart Viewport Management:** Integrated lock-scroll handling that disables background body scrolling whenever the full-screen mobile burger menu is active.

## 🚀 How to Run the Project Locally
Follow these steps to run the project locally:

### 1. Clone the repository

```bash
git clone https://github.com/NemH/Phone_Catalog.git
```

### 2. Navigate to the project directory

```bash
cd Phone_Catalog
```

### 3. Install dependencies

```bash
npm install
```

### 4. Run the project locally

```bash
npm start
```

The application will be available at http://localhost:5173.

The production-ready files will be generated in the dist folder.
